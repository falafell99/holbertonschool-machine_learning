# Word Embeddings

This project explores the fundamental concepts of Natural Language Processing (NLP) and how to represent text data mathematically using word embeddings.

## Learning Objectives
* What is natural language processing?
* What is a word embedding?
* What is bag of words?
* What is TF-IDF?
* What is CBOW and a skip-gram?
* What is an n-gram?
* What is negative sampling?
* The differences between Word2Vec, GloVe, FastText, and ELMo.

## Tasks
* **0. Bag Of Words**: Function that creates a bag of words embedding matrix using `sklearn.feature_extraction.text.CountVectorizer`.
