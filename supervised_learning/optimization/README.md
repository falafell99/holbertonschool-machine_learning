# Optimization

This directory contains projects and exercises focused on optimizing machine learning models, including data normalization, gradient descent variants, and hyperparameter tuning.

## Tasks

| Task | File | Description |
| **4. Moving Average** | `4-moving_average.py` | Calculates EWMA with bias correction to smooth noisy data. |
| **3. Mini-Batch** | `3-mini_batch.py` | Splits data into shuffled mini-batches for efficient training. |
| **2. Shuffle Data** | `2-shuffle_data.py` | Randomly shuffles two matrices while maintaining row correspondence. |
| **1. Normalize** | `1-normalize.py` | Standardizes a matrix using provided mean and standard deviation. |
| :--- | :--- | :--- |
| **0. Normalization Constants** | `0-norm_constants.py` | Calculates the mean and standard deviation of each feature in a matrix. |

## Requirements
* `numpy`
