# Keras: Supervised Learning

This directory contains projects and exercises related to building, training, and deploying neural networks using the **Keras** library (TensorFlow API).

## Tasks

| Task | File | Description |
| **11. Save and Load Configuration** | `11-config.py` | Functions to save and load model architecture as JSON. |
| **10. Save and Load Weights** | `10-weights.py` | Functions to save and load only the weights of a Keras model. |
| **9. Save and Load Model** | `9-model.py` | Functions to save and load entire Keras models. |
| **8. Save Only the Best** | `8-train.py` | Automatically saves the model with the lowest validation loss. |
| **7. Learning Rate Decay** | `7-train.py` | Implements learning rate decay using inverse time decay. |
| **6. Early Stopping** | `6-train.py` | Implements early stopping based on validation loss. |
| **5. Validate** | `5-train.py` | Trains the model with optional validation data. |
| **4. Train** | `4-train.py` | Trains the Keras model using `fit` with mini-batch GD. |
| **3. One Hot** | `3-one_hot.py` | Converts label vectors to one-hot matrices using Keras utils. |
| **2. Optimize** | `2-optimize.py` | Sets up Adam optimization with categorical crossentropy. |
| **1. Input** | `1-input.py` | Builds a Keras model using the Functional API. |
| **1. Input** | `1-input.py` | Builds a Keras model using the Functional API. |
| :--- | :--- | :--- |
| **0. Sequential** | `0-sequential.py` | Builds a Keras `Sequential` model with L2 regularization and Dropout. |

## Requirements
* `tensorflow` (Keras API)
* `numpy`
